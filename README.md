# FilmBox

Desktop app for films and series. **Powered by 1985 Group**

Telegram channel: [@filmbox1985](https://t.me/filmbox1985)

## Downloads

Get the latest build from the **Releases** page of this repository.

- **Windows** — `FilmBox-<version>.exe` installs the app, or use the
  `windows-portable.zip` and run `FilmBox.exe` without installing.
- **macOS** — `FilmBox-<version>-macos-arm64.dmg` for Apple Silicon, or
  the zip for a no-install copy.

The installers are unsigned, so Windows SmartScreen and macOS Gatekeeper
will ask for confirmation the first time. On macOS, right-click the app
and choose Open.

FilmBox uses a decentralised network to discover and fetch films and
series from multiple sources. Playback opens in VLC.
